离线文本传输助手
================

一、选择哪个文件？
优先发给学生：离线文本传输助手-32位通用版.exe
适用于常见的 32 位和 64 位 Windows 电脑。
另提供：离线文本传输助手-64位版.exe，仅用于 64 位 Windows。
兼容目标为 Windows 7 / 10 / 11；不适用于 macOS、Linux 或手机。
无需安装、管理员权限、浏览器、额外运行库或网络。

二、使用方法
1. 双击 EXE。
2. 在左侧粘贴文本（Ctrl+V，或点击“粘贴”）。
3. 点击“生成二维码”。
4. 用微信“扫一扫”扫描右侧二维码。
   如果提示“不支持展示二维码中的文本内容”，点击“复制文本内容”。
   然后打开手机备忘录，粘贴并保存。该提示不代表二维码生成失败。
5. 所有二维码显示在同一个连续页面，按从左到右、从上到下的顺序编号。
   内容多时向下滚动，不需要翻页；Windows 7 可先点击二维码区域再用滚轮。
   逐个扫码复制保存，按顺序拼接，并删除每段开头的标记行。
6. 点击“放大二维码区域”，隐藏输入区并最大化显示；点击“返回编辑”可返回。
   窗口缩放后重新绘制二维码，不拉伸旧图像。
修改文字后，需再次点击“生成二维码”。

三、离线原理与限制
文本直接编码在二维码内，没有网址中转，也不需要手机与电脑相连。
程序没有联网功能，不主动把文本写入文件；关闭窗口即结束。
每段最多 600 个 UTF-8 字节，纯中文约 200 字；每批最多 60 KB。
多段需要人工保存与拼接，不会由普通手机扫码工具自动合并。
这是文本传输工具，不传输图片、Word、Excel 等文件。
部分微信版本的界面可能不同；如没有“复制文本内容”按钮，
需要使用支持纯文本的其他扫码工具。不同工具对空白、换行的复制方式可能不同。
上课前请用学生常用手机测试中文与代码的识别、复制和保存。
对于代码，请核对复制后的缩进和换行。

四、验证情况
已完成：32/64 位 Windows 交叉编译；文本边界与分段检查；
独立解码器对中文、表情、换行、代码及多段二维码逐字节核对；
单页网格布局边界、编号顺序与重叠检查；
窄窗口、宽窗口及恢复窄窗口的四码图像均精确解码通过。
用户已确认微信提示页有“复制文本内容”按钮。
尚未完成：真实 Windows 7/10/11 运行验证、手机复制后的文本核对，
以及手机完全断网时微信扫码与复制的验证。
本程序未做代码签名，Windows 可能显示未知发布者。
若学校策略拦截，请交由机房管理员核验并按学校流程处理。

五、课堂部署
学生只需要 EXE，不需要源码和其他文件。
如果希望重启后仍有程序，请让管理员将 EXE 放进机房还原镜像。
电脑关机前，务必确认手机上的文本已保存且可打开。
