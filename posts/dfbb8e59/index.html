03 定时器实验

Created2026-04-28|Updated2026-10-27|单片机实验
|Post Views:

一、实验目的

  • 掌握定时器/计数器的工作原理；
  • 掌握定时器实现定时功能的软硬件设计。

二、实验设备

  • windows操作系统
  • keil5
  • STC-ISP
  • 蓝桥杯竞赛专用单片机

三、实验内容

S4（P3.3）稳定按下后，P0口所连LED每1秒切换一次亮灭状态（完整亮灭周期为2秒），1秒间隔由定时器实现。S4松开后LED熄灭，再次按下从熄灭状态重新计时。J5置独立按键模式（2、3脚短接接地），并按本页原理图核对。

四、实验原理

定时器概述

STC15系列单片机内置多个定时器/计数器，可用于定时、计数、PWM输出等功能。

定时器 工作模式 中断号 主要用途
Timer0 16位定时/计数 1 定时中断、PWM
Timer1 16位定时/计数 3 定时中断、串口波特率
Timer2 16位自动重装定时/计数 12 定时中断、波特率发生器

定时器工作原理

定时器本质上是一个计数器。在定时模式下，T0/T1可选择系统时钟或系统时钟12分频作为计数时钟；在外部计数模式下则统计外部输入脉冲。16位计数值从65535再加1时溢出，置位相应标志；只有允许相应中断时，CPU才会进入ISR。下面的公式适用于16位定时模式，8位模式应把65536换为256。

定时时间计算公式：

定时器计数周期（不要与STC15 CPU指令执行周期混淆）：

  • 12T模式：计数周期 = 12 / 系统时钟频率
  • 1T模式：计数周期 = 1 / 系统时钟频率（STC15系列支持）

12MHz系统时钟下的计数周期：

模式 计数周期 1ms定时初值
12T 1μs 65536 - 1000 = 64536 (0xFC18)
1T 1/12μs 65536 - 12000 = 53536 (0xD120)

定时器相关寄存器

TMOD寄存器（定时器模式寄存器）：

位 名称 功能
7 GATE1 定时器1门控位
6 C/T1 定时器1计数/定时选择（0=定时，1=计数）
5-4 M1_1, M0_1 定时器1工作模式选择
3 GATE0 定时器0门控位
2 C/T0 定时器0计数/定时选择
1-0 M1_0, M0_0 定时器0工作模式选择

定时器工作模式：

M1 M0 模式 说明
0 0 模式0 16位自动重装定时器（STC15特有）
0 1 模式1 16位定时器（需手动重装）
1 0 模式2 8位自动重装定时器
1 1 模式3 T0：16位自动重装的特殊中断模式；T1：停止计数

STC15F2K60S2的T0模式3并非传统8051的两个8位定时器。该模式中断一经ET0使能，不能再通过EA/ET0屏蔽，且具有特殊高优先级；本实验统一使用普通模式0，不使用模式3。TMOD表仅适用于T0/T1，T2另由AUXR等寄存器配置。

AUXR寄存器（辅助寄存器）：

位 名称 功能
7 T0x12 定时器0速度：1=1T模式，0=12T模式
6 T1x12 定时器1速度：1=1T模式，0=12T模式

TCON寄存器（定时器控制寄存器）：

位 名称 功能
7 TF1 定时器1溢出标志（硬件置1，软件清0或中断响应自动清0）
6 TR1 定时器1运行控制（1=启动，0=停止）
5 TF0 定时器0溢出标志
4 TR0 定时器0运行控制
3 IE1 外部中断1标志
2 IT1 外部中断1触发方式
1 IE0 外部中断0标志
0 IT0 外部中断0触发方式

IE寄存器（中断允许寄存器）：

位 名称 功能
7 EA 总中断允许
3 ET1 定时器1中断允许
1 ET0 定时器0中断允许

定时器初始化步骤

以定时器0为例，定时1ms（12MHz，1T模式）：

  1. 停止并设置模式：TR0 = 0; TMOD &= 0xF0;（模式0、内部定时、无外部门控）
  2. 设置速度模式：AUXR |= 0x80; （1T模式）
  3. 装载初值：TL0 = 0x20; TH0 = 0xD1;
  4. 清标志并开启中断：TF0 = 0; ET0 = 1; EA = 1;
  5. 启动定时器：TR0 = 1;

模式0溢出时由硬件自动重装初值，ISR中不必再次写TH0/TL0。以下示例要求系统时钟实际配置为12MHz；STC-ISP的下载波特率不是系统时钟。若使用其他系统时钟，须重新计算初值。

示例1：定时约500ms后点亮LED

最简单的定时器示例：定时器运行约 500 ms 后点亮全部 LED，此后保持常亮。

示例2：定时器控制LED闪烁

LED每500ms亮灭切换一次，实现真正的闪烁。

示例3：定时器采样按键与1秒亮灭切换

T0始终以1ms节拍运行，按键决定是否累计亮灭时间，不是按下、松开时反复启动停止硬件定时器。连续20次采到S4为低后认为稳定按下，再累计1000个1ms节拍翻转一次；松开时在下一节拍内熄灯并重置状态。松开检测不额外消抖，因此按住期间若出现高电平毛刺也会重新计时。

计数器、消抖计数和LED状态全部只在ISR中读写，主循环不修改它们，也不操作P0/P2。这避免了8位CPU读写16位 unsigned int 时被中断打断，以及两个执行上下文同时选通锁存器的问题。若后续要求主循环读取ISR更新的变量，应声明为 volatile；读取16位快照还须短暂屏蔽相关中断并恢复原使能状态，volatile并不保证多字节访问原子性。

三个示例各自独立运行。示例1、2的计数变量也只在ISR中使用，不涉及运行期间的跨上下文共享。ISR须在下一个1ms节拍前完成；其中不加入软件延时、等待按键或大量串口打印，否则会漏计节拍。观察间隔允许有时钟误差和中断响应延迟，精度以实际系统时钟为准。

五、实验步骤

  • 按照电路原理，在keil中编写程序
  • 将编好的程序下载到单片机
  • 根据实验现象调试程序

六、思考和挑战

  1. 修改程序使灯亮1秒，灭0.5秒。
  2. （选做）修改程序使用定时器T1的中断方式来控制P0.0 、P0.1引脚的LED灯分别以200ms和 800ms的周期闪烁。
