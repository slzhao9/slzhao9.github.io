10 AD转换实验

发表于2026-05-14|更新于2026-11-04|单片机实验
|浏览量:

实验任务速览

本次任务：读取电位器电压，数码管显示学号后两位与整数电压。

必做与选做：按下文实验任务完成；正文明确标为“选做”或“挑战”的内容另行注明完成情况。

课程目录 · 提交与验收说明

一、实验目的

  • 熟悉 Keil C51 软件的使用方法
  • 掌握 I2C 接口的软硬件设计方法
  • 掌握 PCF8591 A/D 转换的实现方法
  • 理解模拟信号到数字信号的转换原理

二、实验设备

  • PC机一台，单片机实验箱

三、实验内容

利用 PCF8591 的 ADC 功能读取电位器电压值，数码管前两位显示学号后两位，最后一位显示电压值（0~5 对应 0V~5V），随电位器旋转变化而实时更新。

四、实验原理

PCF8591 是一个单片集成、单一电源、8位 CMOS 数据采集器件。它具有 4 路模拟输入（AIN0~AIN3）、1 路模拟输出（DAC）和一个串行 I2C 总线接口。PCF8591 的 ADC 采用逐次逼近型 A/D 转换器，DAC 采用256抽头电阻分压链。在蓝桥杯单片机竞赛中，PCF8591 常用于模拟信号的采集与输出。

与 AT24C02 对比：AT24C02 通过 I2C 总线读写数字数据（存储器），PCF8591 通过 I2C 总线读写模拟信号（ADC 采集 / DAC 输出）。两者共用同一套 I2C 底层驱动。

PCF8591 主要特性

特性 说明
模拟输入 4 路（AIN0~AIN3），通过控制字选择
A/D 转换精度 8 位（0~255）
D/A 输出 1 路（AOUT），8 位精度
通信接口 I2C 总线
器件地址 0x90（写）/ 0x91（读）
电源电压 2.5V~6V（单电源）
参考电压 决定 ADC 量程和 DAC 输出范围

ADC 核心概念：

  • ADC（Analog-to-Digital Converter，模数转换器）将连续的模拟电压转换为离散的数字量
  • PCF8591 是 8 位 ADC，转换结果范围 0~255
  • 理想量化步长为 (Vref−VAGND)/256(V_{ref}-V_{AGND})/256(Vref​−VAGND​)/256；本板AGND接0V时，可用 Vin≈ADC×Vref/256V_{in}\approx ADC\times V_{ref}/256Vin​≈ADC×Vref​/256 估计电压
  • 5V参考下128码约为2.50V，255码的标称值约4.98V；同一码对应一个量化区间，不能据此精确还原输入电压

PCF8591 器件地址

PCF8591 的器件地址格式与 AT24C02 类似：

器件类型识别符（常数） 片选信号（硬件连接） 读写方向 备注
D7 D6 D5 D4 A2 A1 A0 R/W
写 PCF8591 1 0 0 1 0 0 0 0 写操作：0x90
读 PCF8591 1 0 0 1 0 0 0 1 读操作：0x91

对比：AT24C02 的器件识别码是 1010（0xA0/0xA1），PCF8591 的器件识别码是 1001（0x90/0x91）。两者地址不同，可以挂在同一条 I2C 总线上。

PCF8591 控制字节

PCF8591 的控制字节用于配置 ADC 通道和 DAC 使能，各位含义如下：

位 名称 说明
D7 0 固定为 0
D6 AOUT 1 = 使能 DAC 输出，0 = 关闭
D5~D4 输入方式 00：4路单端；01：3路差分；10：单端与差分混合；11：2路差分
D3 0 保留位，固定为0
D2 AINC 1：转换后通道号自动递增
D1~D0 通道号 在选定输入方式下选择通道；单端模式0011对应AIN0AIN3

常用控制字：

控制字 二进制 选择的通道 DAC 状态
0x40 0100 0000 AIN0 使能
0x41 0100 0001 AIN1 使能
0x42 0100 0010 AIN2 使能
0x43 0100 0011 AIN3（电位器） 使能

蓝桥杯开发板：CT107D 开发板上 PCF8591 的 AIN3 通道连接电位器，旋转电位器可改变输入电压。因此 ADC 读取使用控制字 0x43。

ADC 读取流程

PCF8591 的 ADC 读取过程分以下几步：

  1. 发送起始信号，发送器件地址 0x90（写模式），告诉 PCF8591 主机要向它发数据。
  2. 发送控制字节（如 0x43），配置 ADC 通道号。这一步是告诉 PCF8591 接下来要转换哪个通道的模拟信号。
  3. 重新发送起始信号（Repeated Start），发送器件地址 0x91（读模式），告诉 PCF8591 主机要读取转换结果。
  4. 先读取并丢弃一个旧结果字节，主机发送ACK，继续接收。
  5. 再读取当前通道的新结果（8位、0~255），主机发送NACK后STOP。

重要提示：PCF8591 的 ADC 第一次读到的数据是上一次转换的结果。每次读事务应连续读两个字节，第一字节后发送ACK，丢弃旧值，再读取第二字节并发送NACK。上电首次旧值为0x80；切换通道时，忽略该细节还可能把前一通道结果当成当前通道结果。

五、实验步骤

  • 按照电路原理，在 keil 中编写程序
  • 将编好的程序下载到单片机
  • 观察数码管前两位是否显示学号后两位，最后一位是否显示电压值
  • 旋转电位器，观察数码管最后一位的电压值是否随之变化
  • 用万用表测量电位器输出电压，与数码管显示值对比验证
  • 根据实验现象调试程序

六、思考和挑战

  1. 如何在数码管上显示保留 2 位小数的电压值（如显示 “2.51”）？提示：按量化步长将 ADC 值换算为单位0.01V的整数（AGND=0、Vref=5V时，标称约0~498），整数部分和小数部分分别送数码管显示。注意 C51 中 unsigned int 为 16 位（最大 65535），如果直接用 adc_val * 500 / 256 会溢出（255×500=127500），需要找一种不溢出的写法。数码管段选码表中小数点由最高位（D7）控制，将段选码的最高位清零即可点亮小数点。
