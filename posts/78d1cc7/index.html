09 AT24C02读写实验

实验任务速览

本次任务：写入学号后8位，读回校验并显示，验证断电保持。

必做与选做：按下文实验任务完成；正文明确标为“选做”或“挑战”的内容另行注明完成情况。

课程目录 · 提交与验收说明

一、实验目的

  • 熟悉 Keil C51 软件的使用方法
  • 掌握 I2C 接口的软硬件设计方法
  • 掌握 AT24C02 读写功能的实现方法

二、实验设备

  • PC机一台，单片机实验箱

三、实验内容

将自己学号的后8位依次写入 AT24C02，从 00H 单元开始存放，然后再读出送数码管显示。

四、实验原理

I2C 总线全称：Inter-Integrated Circuit，是由飞利浦公司开发出来的一种串行总线协议，它是一种多主机的总线，当发生主机竞争时，有总线仲裁机制。

I2C 总线传输数据过程

I2C 总线传输数据过程中涉及以下基本信号：

信号 说明
起始信号 SCL 为高时，SDA 从高变低
停止信号 SCL 为高时，SDA 从低变高
写/发送数据 主机向从机发送一个字节（地址和数据），高位先发
读/接收数据 主机从从机接收一个字节
等待应答 传输过程中，接收方在第 9 个时钟周期将 SDA 拉低
发送应答 读取或写入最后一个字节数据后，发送应答或非应答

应答信号（ACK）规则：

  • 主机发送（写数据）：应答信号由接收方在数据开始后的第 9 个时钟周期发送，在 SCL 为高电平期间，接收方将 SDA 拉为低电平产生应答，用来结束一个字节的传输。
  • 主机接收数据（读数据）：它收到最后一个字节后，必须向从机发出一个结束传送的信号。这个信号是通过对从机的"非应答信号"来实现的，在 SCL 为高电平期间，SDA 为高电平，即主机在第9个时钟保持SDA释放为高，从机随后结束本次发送，主机再产生停止信号。

AT24C02 地址格式

AT24C02 的设备地址格式如下：

器件类型识别符（常数） 片选信号（硬件连接） 读写方向 备注
D7 D6 D5 D4 A2 A1 A0 R/W
写AT24C02 1 0 1 0 0 0 0 0 写操作：0xA0
读AT24C02 1 0 1 0 0 0 0 1 读操作：0xA1

AT24C02 一共有 256 个字节的存储空间，地址从 0x00~0xFF。

I2C 底层驱动–示例代码

本组示例统一使用下列IIC_接口。条件为STC15F2K60S2、系统时钟12MHz、单主机、板载器件及上拉电阻正常、P2.0/P2.1保持准双向或开漏模式。0x90/0x91、0xA0/0xA1均为包含读写位的8位地址字节，要求相应器件A2—A0均接地。

延时不再靠少量NOP猜测：每段至少128条NOP，12MHz下仅NOP时间就约10.7μs，SCL频率低于100kHz，并留出高/低电平时间余量。循环、函数调用和中断会进一步延长时间；这里不声称是精确频率。改变主频或编译器后，应查看汇编或用逻辑分析仪核对：PCF8591要求SCL≤100kHz、高电平≥4.0μs、低电平≥4.7μs。实际波形还受上拉电阻和总线电容影响。

这是用于板载PCF8591/AT24C02的单主机软件示例，不实现多主机仲裁和时钟拉伸；不要与其他任务同时操作这两根线。中断若更新P2锁存器选通位，必须保留P2.0/P2.1；总线断线、短路或返回失败时应提示检查硬件，避免无条件采用读回值。

写数据函数

写数据的流程：

  1. 首先是 I2C 的起始信号，接着跟上首字节，也就是 I2C 的器件地址，并且在读写方向上选择"写"操作。
  2. 发送数据的存储地址。24C02 一共有 256 个字节的存储空间，地址从 0x00~0xFF，想把数据存储在哪个位置，此刻写的就是哪个地址。
  3. 发送要存储的数据。注意在写数据的过程中，EEPROM 每个字节都会回应一个"应答位 0"，如果没有回应答位，说明写入不成功。

关键点：STOP后EEPROM进入内部写周期，期间可能NACK。函数用有限次数ACK轮询判断器件重新就绪，超限返回失败；调用方必须检查返回值。具体写周期上限以板上芯片型号手册为准。ACK表示通信被接收，不保证写保护关闭或内容必然写入，验收还需读回比较。上电正常工作时不要在每次循环中重复写同一学号，避免无意义消耗EEPROM寿命。

读取数据函数

读取数据的流程：

  1. 首先是 I2C 的起始信号，接着跟上首字节，也就是 I2C 的器件地址，并在读写方向上选择"写"操作。注意：这里写操作是为了要把所要读的数据的存储地址先写进去，告诉 EEPROM 要读取哪个地址的数据。
  2. 发送要读取的数据的地址，注意是地址而非存在 EEPROM 中的数据，通知 EEPROM 要哪个单元的信息。
  3. 重新发送 I2C 的起始信号和器件地址，并且在方向位选择"读"操作。在这三步中，每一个字节实际上都是在"写"，所以每一个字节 EEPROM 都会回应一个"应答位 0"。
  4. 读取从器件发回的数据，读一个字节，如果还想继续读下一个字节，就发送一个"应答位 ACK(0)“，如果不想读了，告诉 EEPROM 不想要数据了，就发送一个"非应答位 NAK(1)”。
