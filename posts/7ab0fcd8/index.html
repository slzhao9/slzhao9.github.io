一、实验目的

  1. 领会二叉树的存储结构。
  2. 理解先序、中序、后序和层次遍历的访问顺序。
  3. 掌握二叉树三种递归遍历算法的设计方法。
  4. 掌握利用栈实现先序、中序和后序非递归遍历的方法。
  5. 掌握利用队列实现二叉树层次遍历的方法。

四、实验原理

1. 二叉树存储结构

二叉链表使用一个结点保存当前结点的数据，以及指向左孩子和右孩子的指针。没有左孩子或右孩子时，相应指针为 NULL。

每个结点只保存自己的数据、左孩子地址和右孩子地址。指针为 NULL 表示对应方向没有孩子。一个结点最多有两个孩子，但左孩子和右孩子可以只有一个，也可以都没有。

建立二叉树时，最重要的是不要把“没有孩子”误写成一个空数据结点。没有孩子时应让相应指针为 NULL；叶子结点的左右指针都为 NULL。

2. 三种深度优先遍历

  • 先序遍历：根结点、左子树、右子树，简称 根-左-右。
  • 中序遍历：左子树、根结点、右子树，简称 左-根-右。
  • 后序遍历：左子树、右子树、根结点，简称 左-右-根。

递归遍历直接利用函数调用栈保存遍历过程。非递归遍历需要显式使用栈，模拟递归过程。

可以把递归函数理解为“先处理当前结点，再把同样的任务交给子树”。当参数 b == NULL 时，说明这棵子树为空，函数立即返回；这是递归能够结束的条件。

例如先序遍历访问结点 A 时，程序按照“访问 A、遍历 A 的左子树、遍历 A 的右子树”的顺序执行。每个子树又遵守同样的规则，所以最终得到完整的先序序列。

3. 层次遍历

层次遍历从根结点开始，按照从上到下、从左到右的顺序访问结点。实现时使用队列：访问一个结点后，依次将它的左孩子和右孩子入队。

在非递归深度优先遍历中，栈保存“以后还要处理的结点”。先序遍历把右孩子先入栈，是因为右孩子后出栈，这样左孩子就能先被访问；中序遍历需要先沿左孩子方向入栈，直到没有左孩子后再访问栈顶；后序遍历必须等左右子树都处理完，因而需要两个栈或访问状态记录。

层次遍历使用队列保存“下一层还要访问的结点”。先出队的结点先处理，并按左孩子、右孩子的顺序入队，所以同一层中的结点会从左到右访问。

五、算法设计

1. 递归先序遍历

若当前结点为空，遍历结束；否则先访问当前结点，再递归遍历左子树，最后递归遍历右子树。

2. 非递归先序遍历

根结点先入栈。每次取出栈顶结点并访问，然后先将右孩子入栈，再将左孩子入栈，从而保证左子树先被访问。

3. 递归中序遍历

先递归遍历左子树，再访问当前结点，最后递归遍历右子树。

4. 非递归中序遍历

沿左孩子方向不断将结点入栈；当左孩子为空时，取出栈顶结点并访问，再转向该结点的右子树。

5. 递归后序遍历

先递归遍历左子树，再递归遍历右子树，最后访问当前结点。

6. 非递归后序遍历

可以使用一个栈和一个辅助指针记录最近访问的结点，也可以使用两个栈。使用两个栈时，先将根结点入第一个栈，依次转移到第二个栈，再从第二个栈中取出并访问，即可得到后序序列。

7. 层次遍历

将根结点入队。每次取出队首结点并访问，再将它的非空左孩子和右孩子依次入队，直到队列为空。

八、问题分析

1. 为什么先序非递归遍历要先入栈右孩子

栈具有后进先出的特点。为了让左孩子先出栈、先被访问，需要先将右孩子入栈，再将左孩子入栈。

2. 中序非递归遍历为什么要沿左孩子方向入栈

中序遍历要求先访问最左侧结点。沿左孩子方向入栈可以保存从根结点到当前最左结点的路径，待左子树处理完成后，再返回访问根结点。

3. 后序遍历为什么比先序和中序更复杂

后序遍历要求结点的左右子树都处理完成后才能访问根结点。非递归实现需要记录结点的访问状态，或者使用两个栈调整结点的处理顺序。

4. 四种遍历算法的时间复杂度是多少

每种遍历都需要访问二叉树中的每个结点一次，因此时间复杂度均为 O(n)O(n)O(n)。递归遍历需要函数调用栈，非递归遍历需要显式栈或队列，辅助空间复杂度通常为 O(h)O(h)O(h) 到 O(n)O(n)O(n)，其中 h 为二叉树高度。

九、实验总结

本实验要求使用 C 语言完成二叉树先序、中序、后序和层次遍历的程序框架。递归算法主要依靠函数调用栈，非递归深度优先遍历需要显式栈，层次遍历需要队列。完成各个 TODO 后，可以进一步理解不同遍历顺序与栈、队列之间的关系。
