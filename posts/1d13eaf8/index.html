Keil C51 开发环境安装指南

发表于2026-04-28|更新于2026-10-27|单片机实验
|浏览量:

一、Keil C51 安装与激活

1.1 安装 Keil C51

  1. 安装程序准备

    • 运行 c51v956.exe 安装程序
    • 建议直接安装到 C 盘默认目录，避免路径中包含中文或特殊字符

  2. 安装步骤

    • 双击运行安装程序
    • 按照默认设置完成安装
    • 安装完成后，重启计算机

1.2 Keil C51 许可证与评估版

  1. 安装后可以使用官方 Lite/Evaluation 评估版；C51 评估版有代码容量等限制，超过限制时应使用学校提供的有效许可证或购买商业授权。
  2. 有正式许可证时，按许可证类型及官方说明在 File → License Management 中管理授权；需要计算机 ID（CID）时从该窗口读取。
  3. 本课程不将第三方密钥生成工具作为安装步骤，也不需要为安装工具关闭 Windows 安全防护。

官方评估版限制与许可证说明：Keil Limitations。遇到容量限制时，先检查具体提示，不要把所有编译问题都归因于“未激活”。

1.3 编码设置优化

  1. 问题：Keil 默认使用 ANSI 编码，可能导致中文字符乱码
  2. 解决方案：将编码格式改为 UTF-8
  3. 设置路径：在 Keil 中选择相关设置项，将编码格式修改为 UTF-8 格式

二、STC-ISP 配置工具设置

2.1 STC-ISP 软件说明

  1. 软件版本：使用现有的 stc-isp-xxx.exe 版本，无需频繁更新
  2. 功能用途：单片机程序下载、串口调试、延时计算器等

2.2 STC 单片机型号配置

  1. 添加头文件到 Keil
    • 将 STC 单片机头文件复制到 Keil 安装目录
    • 确保 Keil 能识别 STC15F2K60S2 等型号
  1. 连接验证
    • 单片机连接到电脑后
    • 在 STC-ISP 中查看"串口号"
    • 出现串口只说明 USB 转串口设备已枚举；须以成功读取芯片型号信息或完成下载确认与单片机通信正常
  1. 单片机参数设置
    • 型号选择：本课程芯片为 STC15F2K60S2，以实物丝印及工具读取的芯片信息复核；不要固定选择其他 IAP 型号
    • 时钟频率：12MHz

2.4 功能使用

  1. 软件延时计算器
    • 输入所需延时参数
    • 自动生成延时代码
  1. 硬件仿真功能

三、Keil 项目搭建

3.1 创建项目文件夹

  1. 在合适位置新建文件夹，如 01_exp
  2. 用于存放项目的所有相关文件

3.2 创建新项目

  1. 打开 Keil C51 软件
  2. 点击 Project → New Project

3.3 选择单片机型号

  1. 在设备选择对话框中选择：
    • 数据库：STC MCU Database
    • 型号：STC15F2K60S2
  1. 这边可以选择"否"

3.4 项目文件管理

  1. 展开项目结构
    • 点击 Target 1 右侧的 “+” 号
    • 展开所有项目项
  1. 添加文件
    • 添加新文件：右键菜单选择添加新文件
    • 添加现有文件：将已有源文件添加到项目中

3.6 编译设置

  1. 生成 HEX 文件
    • 确保勾选 Create HEX File 选项
    • 这样编译后会生成用于单片机烧录的 hex 文件
  1. 项目编译

四、注意事项

4.1 安装注意事项

  • 安装或管理正式许可证时，按官方提示使用所需权限
  • 安装路径避免使用中文和特殊字符
  • 安装完成后重启计算机

4.2 下载与时钟注意事项

  • 本课程示例通常按 12 MHz 系统时钟编写，须在 STC-ISP 下载参数中核对实际设置。
  • 下载时先点击“下载/编程”，再使用 MCU 电源开关断电、重新上电。普通复位键不等同于断电冷启动。
  • 下载完成后核对工具显示的实际芯片型号与时钟；软件延时还取决于编译器和优化选项，换工具链后需要重新校准。
