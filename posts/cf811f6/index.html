实验2 常用的网络命令

发表于2026-04-28|更新于2026-11-04|计算机网络实验
|浏览量:

实验任务速览

本次任务：使用网络诊断命令记录地址配置、连通性与路径等结果。

必做与选做：按下文实验任务完成；正文明确标为“选做”或“挑战”的内容另行注明完成情况。

课程目录 · 提交与验收说明

一、实验目的

  1. 掌握 Windows/Linux 环境下常用的网络诊断命令及其参数含义。
  2. 通过命令观察并分析网络接口配置、连通性、路由路径及端口监听状态。
  3. 理解网络层（IP、ICMP）、数据链路层（ARP）及传输层（TCP/UDP）的基本运作原理。
  4. 培养基本的网络故障排查与诊断能力。

二、实验环境

  1. 硬件：连接至局域网（或互联网）的个人电脑。
  2. 操作系统：Windows 10/11（主环境），建议配合上一实验的 Linux 虚拟机对比操作。
  3. 工具：命令提示符（CMD）或 PowerShell、终端（Terminal）。

三、实验内容及步骤、结果

1. 网络配置查看命令：ipconfig

  • 实验步骤：
    1. 打开 CMD，输入 ipconfig 查看基础信息。
    2. 输入 ipconfig /all 查看详细信息（包括 MAC 地址、DNS 服务器、DHCP 租约等）。
  • 记录结果：
    • IPv4 地址：____________________
    • 默认网关：____________________
    • 物理地址（MAC）：____________________
    • DNS 服务器：____________________

2. 连通性测试命令：ping

  • 实验步骤：
    1. ping 127.0.0.1：测试本地回环地址，验证 TCP/IP 协议栈是否正常。
    2. ping [网关IP]：测试与出口路由器的连接。
    3. ping www.baidu.com -t：持续测试外网稳定性（按 Ctrl+C 停止）。
    4. ping -l 1000 [目标IP]：改变数据包大小进行测试。
  • 结果分析：
    • 观察并记录"字节"、"时间（ms）"和"TTL（生存时间）"的变化。
    • 思考：TTL 的值反映了什么？

3. 地址解析协议命令：arp

  • 实验步骤：
    1. 输入 arp -a：查看当前主机的 ARP 缓存表。
    2. 找到网关 IP 对应的物理地址，观察其类型（动态/静态）。
    3. （可选）使用 arp -d * 清空缓存（需管理员权限），再次执行 ping 某个内网 IP，观察 ARP 表的变化。
  • 记录结果：
    • 记录网关的 IP 与 MAC 对应关系：____________________

4. 路由跟踪命令：tracert (Windows) / traceroute (Linux)

  • 实验步骤：
    1. 输入 tracert www.google.com 或 tracert www.tsinghua.edu.cn。
    2. 观察数据包经过了多少个跃点（Hop），哪些节点出现了请求超时（*）。
  • 结果分析：
    • 记录到达目标地址经过的总跃点数：____________________
    • 分析：为什么中间会出现星号（*）？

5. 网络统计命令：netstat

  • 实验步骤：
    1. 输入 netstat -an：查看所有开放的端口及连接状态（LISTENING, ESTABLISHED）。
    2. 输入 netstat -r：查看本机的路由表（等同于 route print）。
    3. 输入 netstat -ano：查看每个连接对应的进程 PID。
  • 记录结果：
    • 找出一个状态为 ESTABLISHED 的连接，记录其本地地址与外部地址。

6. 域名查询命令：nslookup

  • 实验步骤：
    1. 输入 nslookup www.edu.cn：查询该域名的 IP 地址。
    2. 输入 nslookup -type=mx [域名]：查询该域名的邮件服务器记录。
  • 记录结果：
    • 查询到的非权威应答结果 IP：____________________

四、思考题

  1. TTL 的作用是什么？
    如果在 ping 命令中发现 TTL 的值从 64 变成了 50，这意味着什么？

  2. ARP 协议的作用是什么？
    为什么在第一次 ping 局域网内一台新主机时，第一个包通常会出现延时或丢失，而之后的包就正常了？

  3. Tracert 原理探究：
    tracert 命令是如何利用 ICMP 协议和 TTL 字段来获取沿途路由器 IP 地址的？（提示：利用了路由器的什么差错报告报文？）

  4. 实战排查：
    如果你的电脑可以登录微信（说明网络层部分通畅），但是无法打开网页，你应该使用哪个命令来排查是否是 DNS 配置出了问题？该如何操作？

  5. 端口与安全：
    执行 netstat -ano 后，如果发现本地有一个可疑的端口（如 4444）处于 LISTENING 状态，你该如何在 Windows 任务管理器中找到并确认这个程序是什么？
