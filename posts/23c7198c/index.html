四、实验原理

1. 带权有向图

有向图中的边具有方向。例如，存在从顶点 i 指向顶点 j 的边时，邻接矩阵中的 A[i][j] 保存该边的权值；反向边需要单独查看 A[j][i]。

本实验约定：

  • 顶点编号从 0 开始；
  • A[i][j] 不为 0 表示存在从 i 指向 j 的边，数值表示边权；
  • A[i][j] == 0 表示不存在从 i 指向 j 的边；
  • 对角线元素通常设置为 0；
  • 若改用包含权值 0 的图，需要另行约定无边标记，避免与合法权值混淆。

读邻接矩阵时，一定要先确认行和列的含义：第 i 行表示从顶点 i 出发，第 j 列表示到达顶点 j。所以 A[i][j] 表示 i -> j，不能把它误读成 j -> i。有向图中的两个方向是相互独立的，填写一个方向不会自动产生反向边。

例如：

表示存在一条从顶点 1 指向顶点 3、权值为 5 的边；如果没有 3 -> 1，则 A[3][1] 仍应保持无边标记。

2. 邻接矩阵

邻接矩阵使用二维数组 edges[n][n] 保存任意两个顶点之间的边信息。对于带权有向图，edges[i][j] 表示从顶点 i 到顶点 j 的边权。

邻接矩阵适合表示边较多的稠密图，判断任意两个顶点之间是否存在边时可以直接访问一个数组元素。

建立矩阵时先准备一个 n × n 的表格，再把每条边放到对应的“起点行、终点列”中。输出时使用外层循环控制行、内层循环控制列，就能完整输出所有顶点对之间的关系。

3. 邻接表

邻接表为每个顶点建立一个单链表，链表中保存从该顶点出发的所有边。边结点至少需要保存目标顶点编号、边权和下一条边的指针。

邻接表只保存实际存在的边，适合表示边较少的稀疏图。创建邻接表时，需要为每条边动态申请一个 ArcNode 结点，并将它连接到对应顶点的边链表中。

例如顶点 1 有两条出边 1 -> 2 和 1 -> 3，邻接表中只在顶点 1 的链表里保存这两条边，不需要为 1 -> 0、1 -> 4 等不存在的边申请结点。

因此，从邻接矩阵转换为邻接表时，可以按行扫描矩阵：扫描第 i 行时，遇到非零元素 A[i][j]，就为出边 i -> j 创建一个边结点。

4. 两种存储结构比较

存储结构 空间复杂度 判断两点是否相邻 遍历某顶点的出边
邻接矩阵 O(n2)O(n^2)O(n2) O(1)O(1)O(1) O(n)O(n)O(n)
邻接表 O(n+e)O(n+e)O(n+e) 通常为 O(degree(i))O(\mathrm{degree}(i))O(degree(i)) O(degree(i))O(\mathrm{degree}(i))O(degree(i))

其中，n 为顶点数，e 为边数，degree(i) 表示顶点 i 的出边数量。

五、算法设计

1. 创建邻接矩阵

将图的顶点数和边数保存到 MatGraph 中，再逐项复制边数组 A。矩阵中的行表示边的起点，列表示边的终点。

2. 输出邻接矩阵

使用两层循环依次输出 edges[i][j]。每一行表示一个起点到所有终点的边信息。

3. 创建邻接表

先初始化每个顶点的边链表为空，再扫描边数组。对于每个非零元素 A[i][j]，动态申请一个边结点，设置目标顶点 j 和权值 A[i][j]，并将其插入顶点 i 的边链表。

插入到链表头部可以简化操作，但输出边的顺序可能与示例中的顺序不同。若实验要求输出顺序与顶点编号从小到大的扫描顺序一致，可以使用尾插法建立邻接表。

4. 输出邻接表

从顶点 0 开始，依次沿每个顶点的边链表访问并输出目标顶点和边权，直到当前链表为空。

5. 销毁邻接表

逐个顶点遍历边链表，依次保存下一条边的地址，释放当前边结点，再继续处理下一条边。所有边结点释放后，再释放邻接表结构体，并将指针设置为 NULL。

八、问题分析

1. 为什么有向图的邻接矩阵通常不对称

邻接矩阵的行表示边的起点，列表示边的终点。有向边只表示一个方向，因此 A[i][j] 和 A[j][i] 可以不同，甚至只有其中一个位置存在边。

2. 邻接表为什么需要动态申请边结点

每个顶点的出边数量不同，使用动态链表可以只为实际存在的边申请空间，避免为不存在的边预留大量存储空间。

3. 采用头插法建立邻接表会有什么影响

头插法实现简单、时间开销小，但输出顺序通常与扫描边数组的顺序相反。如果实验需要保持边的编号顺序，可以改用尾插法，或者在输出时进行相应处理。

4. 销毁邻接表时为什么要先保存下一条边

释放当前结点后，当前指针指向的内存已经不能继续访问。因此应先保存 p->nextarc，再释放 p，最后将指针移动到保存的下一条边。

九、实验总结

本实验要求使用 C 语言完成带权有向图的邻接矩阵和邻接表存储框架。邻接矩阵便于快速判断任意两个顶点之间是否存在边，邻接表适合保存边较少的稀疏图。完成各个 TODO 后，可以掌握图的两种基本存储结构以及邻接表动态内存的申请和释放方法。
