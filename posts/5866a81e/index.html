01 算法性能分析实验

Created2026-10-07|Updated2026-10-07|数据结构实验

一、实验目的

  1. 掌握程序执行时间的基本测试方法。
  2. 理解问题规模变化对算法运行时间的影响。
  3. 观察常见时间函数随问题规模增长的变化规律。
  4. 通过比较不同算法，体会算法设计对程序性能的影响。

二、实验环境

  • 编程语言：C
  • 开发环境：GCC、Clang、Visual Studio、Code::Blocks、VS Code 等
  • 本实验包含 1 个课堂必做任务 + 1 个提高任务 + 1 个选做任务。

三、实验原理

算法性能通常与问题规模 nnn 有关。本实验通过“理论分析 + 实际测试”的方式观察算法效率。

本次实验包含一个课堂必做任务、一个提高任务和一个选做任务：

  1. 必做任务1：比较两种求和算法的运行效率；
  2. 提高任务2：观察常见时间函数的增长趋势；
  3. 选做任务3：比较两种素数判断方法的运行效率。

初学者理解：算法性能到底比较什么

同一个问题可以有不同的解决方法。算法性能主要观察两件事：完成任务需要多少计算步骤，以及程序需要多少额外存储空间。本实验重点观察前者，也就是时间复杂度。

这里的 n 表示问题规模。例如，求 1 到 n 的和时，n 越大，需要处理的数字越多；统计 1 到 n 中的素数时，n 越大，需要检查的数字也越多。

实际运行时间会受到计算机、编译器和当前系统负载影响，所以不能只比较某一次测得的秒数。更可靠的做法是：在同一台计算机上使用相同的编译方式，逐渐增大 n，观察运行时间的增长趋势。

初学者理解：为什么要分析增长趋势

假设一种方法需要执行大约 n 次操作，另一种方法只需要固定几次操作。当 n 很小时，两者可能都很快；当 n 变大时，前一种方法的运行时间会随着 n 增长，而后一种方法变化很小。

因此，时间复杂度不是精确的秒数，而是描述问题规模变大后，算法执行步骤如何增长：

  • O(1)O(1)O(1)：操作次数基本不随 n 改变；
  • O(n)O(n)O(n)：n 增大一倍，操作次数大致也增大一倍；
  • O(n2)O(n^2)O(n2)：n 增大一倍，操作次数大致增大四倍。

实验中应同时记录计算结果和运行时间。只有结果正确，时间比较才有意义；如果只测时间而不检查结果，可能是在比较两个错误程序。

五、算法设计

任务1：两种求和算法的性能比较

对于给定正整数 nnn，计算：

1+2+⋯+n1+2+\cdots+n 1+2+⋯+n

分别采用：

  • 方法1：逐项累加；
  • 方法2：利用求和公式直接计算。

建议测试：

n=104, 105, 106, 107n=10^4,\ 10^5,\ 10^6,\ 10^7 n=104, 105, 106, 107

另做一组个性化测试：令 k 为本人学号末两位组成的整数（末两位为 07 时 k=7），取 n=10001+k。截图中同时显示学号、姓名、k、该组 n 和两种求和结果。

要求：

  1. 分别实现两种方法；
  2. 记录两种方法的计算结果和运行时间；
  3. 检查两种方法的计算结果是否一致；

方法 1 会从 1 开始逐项累加到 n，循环执行次数与 n 直接相关，因此属于线性增长。方法 2 使用公式 n(n+1)/2，无论 n 多大都只需要有限次算术运算，因此属于常数级增长。两种方法的结果必须相同，区别在于获得结果所需的步骤数量不同。

对于：

n=1,2,…,10n=1,2,\ldots,10 n=1,2,…,10

log⁡2n,n,n,nlog⁡2n,n2,n3,2n,n!\log_2n,\quad \sqrt n,\quad n,\quad n\log_2n,\quad n^2,\quad n^3,\quad 2^n,\quad n! log2​n,n​,n,nlog2​n,n2,n3,2n,n!

要求：

  1. 使用循环依次处理 n=1∼10n=1\sim10n=1∼10；

这些函数的增长速度不同。log₂n 增长最慢，n 是线性增长，n² 和 n³ 增长更快，2ⁿ 和 n! 在 n 较大时会迅速增长。循环中的每个 n 都要单独计算，不能把上一次循环的结果误认为当前结果。

本任务为选做题。完成任务1后仍有余力的学生可继续完成，不作为本次实验的基本完成要求。

分别使用两种方法判断一个整数是否为素数，并统计 111 到 nnn 中素数的个数。

  • 方法1：从较小整数开始逐个试除；
  • 方法2：在方法1基础上缩小不必要的试除范围。

建议测试：

n=1000, 5000, 10000, 50000n=1000,\ 5000,\ 10000,\ 50000 n=1000, 5000, 10000, 50000

要求：

  1. 分别编写两个素数判断函数；
  2. 分别统计素数个数并计时；
  3. 检查两种方法统计结果是否一致；

判断素数时，先排除小于 2 的数，因为素数必须是大于 1 的正整数。基础方法可以尝试多个除数；改进方法只需要尝试到平方根，因为如果一个数存在大于平方根的因数，那么它一定同时存在一个小于平方根的因数。统计时应遍历每个候选数，并在判断函数返回真时增加计数。
