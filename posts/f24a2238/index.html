实验7 FTP服务配置

发表于2026-04-28|更新于2026-11-04|计算机网络实验
|浏览量:

实验任务速览

本次任务：配置FTP服务及客户端，验证文件上传与下载方向。

必做与选做：按下文实验任务完成；正文明确标为“选做”或“挑战”的内容另行注明完成情况。

课程目录 · 提交与验收说明

一、实验目的

  1. 理解 FTP（File Transfer Protocol）协议的基本原理，掌握主动模式与被动模式的区别。
  2. 掌握在华为路由器上配置 FTP 服务器的方法，包括用户创建、权限设置及 FTP 目录指定。
  3. 掌握 FTP 客户端的基本操作，包括连接、上传（put）、下载（get）、目录管理等命令。
  4. 能够通过实际操作验证 FTP 文件传输功能，理解 FTP 在网络管理中的应用场景。

二、实验环境

  1. 硬件：个人电脑（建议内存 8G 以上，以流畅运行 eNSP）。
  2. 软件：
    • eNSP V100R003 或更高版本。
    • VirtualBox（eNSP 运行底座）。

三、实验内容及步骤、结果

1. 拓扑搭建

  • 操作：
    1. 打开 eNSP，新建拓扑。
    2. 在左侧设备栏选择 路由器 (Router)，拖入两台 AR2220 路由器。
    3. 使用 连接线 (Copper)，将路由器 FTP Client 的 GigabitEthernet 0/0/0 与 FTP Server 的 GigabitEthernet 0/0/0 直连。
    4. 点击工具栏的"开启"按钮，等待设备图标由红变绿。

2. FTP Client 基础配置

FTP Client：

配置 FTP Client 接口 IP 地址为 10.0.12.1/24，并保存当前配置文件为 1.cfg，用于后续 FTP 上传测试。

3. FTP Server 基础配置与 FTP 服务开启

FTP Server：

关键配置说明：

  • local-user test password cipher 123456：创建 FTP 用户，用户名 test，密码 123456，密文存储。
  • privilege level 15：赋予最高管理权限（0-15 级，15 级为最高）。
  • service-type ftp：指定该用户仅用于 FTP 服务。
  • ftp-directory flash:：设置用户的 FTP 根目录为 flash 存储根目录。
  • ftp server enable：全局开启 FTP 服务器功能。

4. FTP Client 连接 FTP Server 并执行文件操作

FTP Client：

FTP 常用操作说明：

  • ftp 10.0.12.2：连接 FTP 服务器，输入用户名 test 和密码 123456 登录。
  • dir：查看远程目录文件列表。
  • ascii / binary：切换传输模式（ASCII 文本模式 / 二进制模式）。
  • cd / cdup：进入子目录 / 返回上级目录。
  • mkdir / rmdir：创建 / 删除远程目录。
  • put 1.cfg：将本地的 1.cfg 上传至 FTP 服务器。
  • get 2.cfg：从 FTP 服务器下载 2.cfg 到本地。
  • quit：断开 FTP 连接。

5. 结果验证

  • 在 FTP Server 上查看是否收到 Client 上传的 1.cfg 文件。
  • 预期结果：FTP Server 的文件列表中出现 1.cfg 文件，说明文件上传成功。

四、思考题

  1. FTP 传输模式：FTP 的主动模式（Active）和被动模式（Passive）有什么区别？在什么场景下需要使用被动模式？
  2. 权限等级：本实验中将 FTP 用户权限设置为 15 级（最高级），如果设置为较低权限（如 3 级），FTP 操作会有什么影响？
  3. ASCII 与 Binary：FTP 中 ascii 和 binary 两种传输模式分别适用于什么类型的文件？如果用错误模式传输文件会有什么后果？

五、实验中的问题及心得

提交与验收清单
