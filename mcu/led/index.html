知识点：循环移位与低电平驱动

1. 硬件连接 (灌电流驱动)

51单片机IO口拉电流能力弱，灌电流能力强。因此通常采用低电平驱动：

  • LED阳极接 VCC (电源)。
  • LED阴极串联限流电阻接 P1口。
  • P1输出 0 -> 电位差形成 -> 电流流过 -> 灯亮。
  • P1输出 1 -> 无电位差 -> 灯灭。

2. 核心逻辑 (位移)

要实现流水灯，就是让 0 的位置不断移动。以C语言为例：

#include <intrins.h> // 包含 _crol_ 函数 void main() { unsigned char temp = 0xFE; // 1111 1110 (P1.0亮) while(1) { P1 = temp; Delay(500); // 循环左移 1 位 temp = _crol_(temp, 1); // 结果变化: 11111110 -> 11111101 -> 11111011 ... } }

3. 演示说明

左侧控制面板可以调节延时函数的长度（速度）。点击“暂停”后，使用“单步”按钮可以清晰地观察每一次位移操作后寄存器值的变化。
