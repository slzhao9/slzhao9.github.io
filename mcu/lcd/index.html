01 / 1602 是什么

1602 表示每行 16 个字符、共 2 行，不是 160×2 像素。常见字符单元为 5×8 点阵，由 HD44780 或兼容控制器驱动。

MCU 发送指令和字符编码，LCD 控制器负责刷新；与数码管不同，程序不需要逐位持续扫描。

CGROM 存放固定字模，CGRAM 存放用户字模，DDRAM 保存字符编码。不同 ROM 版本的符号和日文字符可能不同；本页使用教学用 ASCII 字模。

03 / DDRAM 与定位

双行模式共有 80 字节，地址为 00H–27H、40H–67H。屏幕仅显示其中两组 16 个字符。

设置地址：0x80 | addr。第一行第 c 列：0x80+c；第二行：0xC0+c，c 从 0 开始。

第 16 列后写入的是隐藏位置，不能依赖自动换行；第二行需要明确设置地址。点击上方屏幕可观察地址变化。

04 / 4 位与 8 位接口

8 位：一次 E 脉冲传一个字节。4 位：先高四位、再低四位，每个半字节各产生一次 E 脉冲，均走 DB4–DB7。

例如 0x41（A）在 4 位模式发送 0100 → 0001。两次传输期间 RS 保持一致。

4 位省 4 根 IO，字符分辨率不变。I²C 背包属于扩展 IO 转并行接口，并非 HD44780 原生 I²C。

07 / 上电初始化

以 5 V、HD44780U 手册条件为例：电源稳定后等待超过 15 ms，发送初始化高半字节 3；等超过 4.1 ms，再发 3；等超过 100 µs，再发 3。

4 位模式再发高半字节 2，然后按完整字节发送 28H → 08H → 01H → 06H → 0CH。8 位模式对应 38H。

初始化握手先确保接口同步，之后才能按正常格式传输；等待值需结合供电、振荡频率和兼容芯片手册确定。本页重新初始化会逐步展示这一过程。

08 / 时序与延时

数据建立、E 高电平宽度、保持时间都必须满足规格。HD44780U 在 4.5–5.5 V 条件下写 E 高电平最短 230 ns，E 周期最短 500 ns；低电压条件不同。

在内部振荡 270 kHz 条件下，多数指令执行上限 37 µs，清屏 / 归位 1.52 ms。实际速度随振荡频率变化，不能把它们视为所有模块的统一等待值。

可轮询 BF，或按所用模块最坏情况加裕量延时。本页慢放时间并非真实执行延时。

09 / CGRAM 自定义字模

5×8 模式可定义 8 个字符，每个占 8 字节；每行仅低 5 位控制像素。

槽 n 的首地址为 0x40 | (n×8)，依次写入 8 行，然后设置 DDRAM 地址，再写字符码 0–7。

修改 CGRAM 会改变所有引用该槽的字符。自定义字模易失，掉电后需要重新写入；这不能扩展为完整中文字库。

10 / 51 单片机驱动流程示例

// 伪代码：GPIO、E 时序和等待函数按硬件实现
void lcd_write(unsigned char rs, unsigned char value) {
    wait_ready();       // 读 BF 或使用足够的固定延时
    RS = rs; RW = 0;
    if (mode4) {
        put_DB7_4(value >> 4); pulse_E();
        put_DB7_4(value & 15); pulse_E();
    } else { put_DB7_0(value); pulse_E(); }
}
// 完成上电初始化后
lcd_write(0, 0x80);     // 第一行第一列
lcd_write(1, 'H');
lcd_write(0, 0xC0);     // 第二行第一列
lcd_write(1, 'A');
// 写字符串时自行处理第16列边界和第二行定位

11 / 常见故障排查

  • 背光亮、无字符：检查 VO、供电、初始化及 RS/E。
  • 出现一排黑块：先调对比度，再检查初始化与接口模式。
  • 乱码 / 丢字：检查 E 时序、数据建立时间、忙等待和 4 位高低顺序。
  • 第二行不显示：确认两行配置、发送 C0H 定位。
  • 短字符串残留旧尾巴：补空格覆盖剩余列，或清屏后重写。
  • 频繁清屏闪烁：只更新变化区域，避免每帧清屏。
